# Shreya Singh | Personal Portfolio

A responsive personal portfolio website built using HTML, CSS, and JavaScript to showcase my skills, education, projects, and contact information.

## Live Demo

[View My Portfolio](https://devbyshreya.github.io/Shreya-portfolio/)

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## Features

- Responsive design
- Interactive navigation with smooth scrolling
- Skills and education sections
- Projects showcase with GitHub links
- Dark mode toggle with saved preferences
- Contact form with a prefilled email draft
- Scroll reveal animations
- Dynamic copyright year

## Run Locally

Clone this repository:

```bash
git clone https://github.com/devbyshreya/Shreya-portfolio.git
```

Open the project folder in VS Code and run `index.html` using your browser or the Live Server extension.
